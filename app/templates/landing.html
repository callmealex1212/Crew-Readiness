It learns you

A few routine checklist sessions set each person's own usual timing. Nobody is compared with anybody else.

It notices what changed

Typing rhythm, pauses and response time against that baseline. Only nine timing numbers leave the browser, never the words.

A person decides

A change is a prompt for a check-in, not a verdict. A reviewer can accept a new normal. The system cannot.
