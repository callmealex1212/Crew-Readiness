01The problem

Scoring each feature against the person's own median raised a false alert on about {{ (data.incumbent_false_alerts_at_yellow * 100) | round(0) | int }} % of normal sessions at the YELLOW level. Most came from pause time: pauses are small counts (usually 0 or 1), so the usual spread measure is often zero and one ordinary pause looks huge.

02The change

Pause count is now scored with a per-person count model: their own average and their own burstiness, learned from their own history. The output is "how often would a count this high happen for this person", shown to the reviewer in those words.

04If our assumption is wrong

The model needs a starting guess for how bursty pausing is. We changed the guess and the true burstiness of the simulated people (10 % slowdown, same false-alert rate). The win barely depends on the guess, because burstiness is learned per person.

05What this does not show
  • {% if pilot %}Mostly simulated data, plus a small volunteer pilot.{% else %}Simulated data only.{% endif %} We wrote the simulator and the model. No real crew, no astronaut data.
  • The gain is real but modest; it is a measured improvement with a stated cause, not a breakthrough.
  • Pause time is displayed but no longer scored, so one very long pause can go unflagged.
  • The typing and checklist features still use the original method and are not yet re-tested.
  • It detects changes in interaction timing against a person's own history. It does not detect fatigue, illness or fitness for duty.
